# Credential Generation Fix

## Problem Identified

The backend was generating its own credentials instead of using the credentials generated by the frontend, causing a mismatch between what's emailed and what's stored in the database.

## Frontend Credential Generation (emailService.js)

- Username: `25-65677` (year + 5 random digits)
- Password: `lxh858` (3 letters + 3 numbers)

## Backend Issue

The old backend function was:

1. Ignoring the `username` and `password` from `req.body`
2. Generating its own credentials with different format
3. Storing different credentials than what was emailed

## Solution Applied

Updated backend function now:

1. ✅ Uses credentials from frontend if provided (`req.body.username` and `req.body.password`)
2. ✅ Falls back to same generation logic as frontend if not provided
3. ✅ Stores the SAME credentials that are emailed to the user
4. ✅ Uses database transactions for data integrity
5. ✅ Handles both new credential creation and updates
